# Omarchy Blue Sky

A light Omarchy theme: pale sky backgrounds, clear blue accents.

Install:

```bash
omarchy theme install https://github.com/robert-flo/omarchy-bluesky-theme.git
```

The installer clones the repo as `bluesky` (`omarchy-` prefix and `-theme` suffix are stripped).

Switch later with:

```bash
omarchy theme set bluesky
```
